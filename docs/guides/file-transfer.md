# ファイルを転送する

[ドキュメント一覧](../README.md)

**FileTransfer** では、接続先 PC 同士、または手元の PC と接続先 PC の間でファイルをコピーできます。

| 方法 | コピーする場所 | 画面を閉じた場合 |
| --- | --- | --- |
| クラスター · ホスト ↔ ホスト | CoreService が動く PC 同士 | 受け付け済みの転送は続行します。 |
| Browser ↔ ホスト | ブラウザーを開いている PC と接続先 PC | 転送を続けるには画面を開いておく必要があります。 |

ワークフローから転送する場合は、[ファイルノード](../reference/nodes/files.md)の `file.transfer` を使用してください。

## PC 同士でコピーする

1. **FileTransfer** → **Cluster · Host ↔ Host** を開いてください。
2. 転送に使うクラスターと、左右の PC を選択してください。「自動」では、両方の PC に共通する利用可能なクラスターが選択されます。
3. 左右のフォルダーを開き、コピーする項目を選択してください。
4. 転送ボタンを押すか、相手側のフォルダーへドラッグしてください。
5. 転送キューで完了を確認してください。

ファイルは移動ではなくコピーされます。空フォルダーもコピーできます。
同名の項目は上書きされません。

キューはコピー先の CoreService に保存されます。
CoreService の再起動時には待機中の要求が復元されますが、開始済みだったコピーは結果不明として残り、自動では繰り返されません。

## 手元の PC とコピーする

1. **Browser ↔ Host** を開き、接続先の PC を選択してください。
2. 「ローカルフォルダーを選択」から手元のフォルダーを選び、ブラウザーの読取り・書込みを許可してください。
3. 左右のフォルダーを開き、項目を選択してコピーしてください。
4. 完了するまで画面を開いたままにしてください。

フォルダー選択に対応しないブラウザーでは、通常のファイル選択によるアップロードと、ブラウザーの保存機能によるダウンロードを使用できます。
中断したフォルダーには、コピー済みのファイルが残る場合があります。

## フォルダーを開く・作成する・削除する

- フォルダーはダブルクリック、または選択後に Enter で開いてください。
- **↑ Up** で親フォルダー、**Drives** でドライブ一覧へ戻れます。
- 新規作成する場合は、作成先を開いて「フォルダー作成」を使用してください。
- 削除する場合は、項目を選択して「選択項目を削除」を押し、対象 PC・パス・項目を確認してください。

**削除した項目はゴミ箱へ移動されません。フォルダーは内容も削除されます。**

## 失敗・結果不明になった場合

転送率が 100% でも、保存内容の検証と確定が終わるまでは成功ではありません。
結果不明の場合は、元の操作結果とコピー先を確認してから、再度コピーするか判断してください。

接続先のファイル操作には、対象 CoreService の OS アクセス権が使われます。
通信・件数上限・追加ネットワークの設定は[ファイル転送の設定と制約](../reference/file-transfer.md)を参照してください。
