# Clutch-CS をインストールする

[ドキュメント一覧](../README.md)

Windows 版のセットアップでは、CoreService と管理画面（Web クライアント）を導入できます。
最初の PC でクラスターを作成し、2 台目以降はそのクラスターに参加させてください。

## 準備する

- 配布 ZIP をフォルダーごと展開してください。実行ファイルと `files` フォルダーは同じ場所に置いてください。
- 同じクラスターで使うすべての PC を、同じネットワークに接続してください。
- 推奨設定での導入には管理者権限が必要です。

## 最初の PC に導入する

1. 展開先の **Clutch-CS-Setup.exe** を起動してください。
2. 言語を選択し、「インストール」へ進んでください。
3. ライセンスを最後まで確認し、確認欄にチェックを入れてください。
4. Clutch-CS で使うネットワークを一つ選択してください。選択したネットワークでクラスターの検索が始まります。
5. 「新しいクラスターを作成する」を選択し、クラスター名とポート番号を指定してください。
6. コンピューター名（ホスト名）と登録名（ピア名）を確認してください。優先順位は自動設定を選択できます。
7. 管理画面のインストール有無とポート番号を確認し、「推奨設定」または「高度な設定」を選択してください。
8. 「実行内容の確認」で内容を確認し、チェックを入れてから「インストール」を押してください。
9. 完了画面で結果を確認してください。管理画面をインストールした場合は、表示された URL から開けます。再起動は「今すぐ再起動」または「後で再起動」を選択できます。

推奨設定では、セットアップが CoreService を `C:/Clutch-CS/{クラスター名}` にサービスとして配置します。
高度な設定では、実行権限、配置先、管理画面の表示などを変更できます。

## 2 台目以降を追加する

1. 既存の PC が起動し、管理画面で `Ready` になっていることを確認してください。
2. 追加する PC でセットアップを起動し、既存の PC と同じネットワークを選択してください。
3. 「既存のグループ（クラスター）に参加する」を選択し、参加先を確認してください。
4. 以降は最初の PC と同じ手順でインストールしてください。

検索結果にクラスターがある場合は、最初の候補が選択されます。
見つからない場合は、ネットワークと既存 PC の状態を確認してから再検索してください。参加先が見つからないことを理由に、同じ名前の新規クラスターを作成しないでください。

## 管理画面の起動と権限

Web クライアントは CoreService とは独立したプログラムです。

| 設定 | 起動方法・保存先 |
| --- | --- |
| 既定 | 通常ユーザーの権限でサインイン時に起動し、ユーザーごとにデータを保存します。 |
| サービスとして起動する（PC 共通） | 高度な設定から選択できます。サービスとして起動し、PC 共通の保存先を使います。 |
| 既存の Web クライアントがある | 既存の設定とポート番号を維持します。 |

Windows Firewall には、選択したネットワークで必要な UDP ポートと、CoreService の TCP・UDP 通信を許可するルールを登録します。
サービスの実行ファイル・設定は管理者と SYSTEM が変更でき、一般ユーザーには読取り・実行権限を付与します。

## 完了後の確認

[管理画面を使う](web-client.md)の手順で、導入した PC が `Ready` になっていることを確認してください。
管理画面を閉じても CoreService は動作を続けます。

失敗した場合は、結果画面の「詳細」に表示された理由と操作 ID を確認してください。
既存の配置を削除してやり直す前に、[保守の手順](maintenance.md)または[トラブルシューティング](troubleshooting.md)で対処方法を確認できます。

設定ファイルを用意して導入する場合は、[スクリプトによる導入](manual-install.md)を参照してください。
