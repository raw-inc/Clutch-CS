# ネットワーク通信を調べる

[ドキュメント一覧](../README.md)

**SignalScope** では、複数の PC で取得したパケットを一つの画面にまとめて確認できます。
取得・閲覧・検索に対応しています。

## パケットを取得する

1. ヘッダーの **SignalScope** を開いてください。
2. 左側で取得する PC を選択してください。
3. 各 PC のネットワークアダプターと取得方式を選択してください。利用できない方式には理由が表示されます。
4. **Start** を押してください。
5. 一覧の行を選択し、解析結果と Hex / ASCII 表示を確認してください。

取得元を変更する場合は、先に **Stop** を押してください。
一部の取得元で開始に失敗した場合も、開始できた取得元とは区別して表示されます。

## 検索する

検索欄では、IP、ポート、プロトコル、ホスト名、Info の内容などを検索できます。
複数の語を指定する場合は AND / OR と括弧を使用できます。

~~~text
OSC AND (192.168.10. OR 192.168.20.) AND "/address/to" AND "ready"
server-host AND "/status"
~~~

最初の例は、`192.168.10.` または `192.168.20.` で始まる IP アドレスと、`/address/to`・`ready` を含む OSC 通信を検索します。IP アドレス、OSC アドレス、値は調べたい通信に合わせて変更してください。

検索は表示を絞り込む機能です。一致しないパケットも、保持上限内では取得側に残ります。
検索式と詳細検索の条件は[通信キャプチャの仕様](../reference/network-capture.md#リアルタイム検索)を参照してください。

## 停止・終了する

- **Stop** は取得を止めます。取得済みの内容は引き続き確認できます。
- **クリア** は保持している内容を消します。取得状態と検索条件は維持されます。
- 画面を離れると、取得プロセスと接続が終了します。

キャプチャ本文や検索式は永続保存されません。
一覧に残っていても、詳細が保持上限から外れている場合があります。

## 必要な権限と取得方式

Windows では OS 標準の Packet Monitor、または導入済みの Npcap を使用します。
Packet Monitor には管理者権限が必要です。Linux・macOS では導入済みの libpcap と、OS 側のキャプチャ権限を使用します。

ドライバーは同梱・自動導入されません。
Npcap を使用する場合は、独自ライセンスの条件を確認してください。[取得方式・ライセンス・対応環境](../reference/network-capture.md#実行環境と構成)に記載しています。
