# PC の設定を変更する

[ドキュメント一覧](../README.md)

**HostManager** では、接続先 PC のネットワーク、電源、画面などの OS 設定を変更できます。
利用できる機能は、対象 PC の OS と CoreService の実行権限によって変わります。

## 対象と設定項目を選ぶ

1. ヘッダーの **HostManager** を開いてください。
2. 左側の一覧で対象の PC を選択してください。複数台を選択することもできます。
3. 変更する設定のタブを開き、取得された現在値を確認してください。
4. 変更する項目を入力し、「変更内容を確認」を押してください。
5. PC ごとの変更前・変更後と影響を確認してから適用してください。

取得できない PC や未対応の機能は選択できません。
NetworkIF と Firewall の変更では、通信に影響することの確認が必要です。

## 設定項目を探す

| タブ | 設定する内容 |
| --- | --- |
| NetworkIF | IP アドレス、DHCP、DNS、ゲートウェイ、Hyper-V のネットワーク |
| Hosts | hosts ファイルのエントリー |
| Firewall | Windows Firewall のプロファイルとローカルルール |
| PATH | PATH を含む永続環境変数 |
| Display | ディスプレイの解像度・リフレッシュレート |
| Power | スリープ、ディスプレイオフ、電源ボタンなど |
| 電源スケジュール | 日時・曜日を指定した起動要求とシャットダウン |
| Windows Update | Windows の自動更新に関する設定 |
| Login | ローカルユーザーの自動ログイン |
| Wake-on-LAN | 起動要求に使用するネットワークアダプター |

OS ごとの対応状況、入力値、適用条件は[PC 管理の設定項目](../reference/pc-management.md)で確認できます。

## 適用結果を確認する

ページ上部の「操作履歴」で、進捗と結果を確認してください。
適用後は対象 PC の現在値が再取得されます。

確認画面を開いている間に設定や対象プロセスが変わると、適用は拒否されます。内容を再取得して確認してください。
通信が切れた操作は「結果不明」になる場合があります。同じ変更を繰り返す前に、元の操作結果を確認してください。

## 電源操作の注意点

Wake-on-LAN の送信成功は、PC の起動完了を意味しません。起動後の状態も確認してください。
予約した起動要求を送るには、担当クラスター内で別の PC が稼働している必要があります。

シャットダウンは進行中のワークフローの完了を待ちません。
運用に影響しない時刻と対象を確認してから設定してください。
