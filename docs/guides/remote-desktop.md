# 画面を遠隔操作する

[ドキュメント一覧](../README.md)

**RemoteDesktop** では、Windows PC の画面・再生音声を確認し、マウスやキーボードで操作できます。
接続先はログイン中の Windows デスクトップです。
映像コーデックの既定は VP9 です。H.264・H.265 は `/desktop?experimental=true` で開いた場合だけ選択できます。

## 接続する

1. [管理画面の接続設定](web-client.md#接続先を設定する)で、対象 PC を確認できる状態にしてください。
2. ヘッダーの **RemoteDesktop** を開き、接続先のホストを選択してください。
3. **Connect** を押してください。
4. 上部のモニターアイコンでディスプレイを選択してください。**All screens side by side** では複数画面を横に並べて表示できます。
5. 操作する場合は映像をクリックしてください。

画面にフォーカスがある間、キーやマウス操作が接続先へ送られます。
確認だけを行う場合は「未操作」を有効にしてください。映像・音声を受信しながら、操作の送信を止められます。

## 表示・音声・入力を切り替える

| 操作 | 使用する項目 |
| --- | --- |
| 音声を消す・戻す | Mute audio / Unmute audio |
| 操作欄も含めて全画面にする | Fullscreen |
| 映像だけを全画面にする | 1 画面表示中の Video fullscreen |
| キーボードを表示する | 上部のキーボードボタン |
| 画質・通信の状態を見る | Statistics overlay、左側の接続設定・詳細 |

同じ PC へ接続すると音声は既定でミュートされます。必要な場合は解除できます。
映像だけの全画面表示では、Esc は接続先に送られず、全画面の解除に使われます。

## 接続を終える

**Disconnect** を押してください。
画面の移動やブラウザーの終了でも接続は終了します。押したままのキーや未送信の入力は次の接続に持ち越されません。

「自動再接続」は既定で有効です。通信断の場合は同じ PC への接続を試みますが、手動で切断した場合は再接続しません。

## 映像が遅い・止まる場合

統計表示で受信速度、表示 FPS、遅延を確認してください。
画質やコーデックの設定を変える場合は、[リモートデスクトップの設定と制約](../reference/remote-desktop.md)を参照してください。

接続先にログイン中のデスクトップがあるか、ClientHost と CoreService の間で TCP 通信が許可されているかも確認してください。
接続が切れた理由は[トラブルシューティング](troubleshooting.md)で切り分けられます。
