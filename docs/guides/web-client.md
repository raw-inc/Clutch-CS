# 管理画面を使う

[ドキュメント一覧](../README.md) · [前へ：インストール](install.md) · [次へ：ワークフローを作る](workflows.md)

管理画面では、PC の状態確認、ワークフローの編集、ログの検索、遠隔操作ができます。
画面を配信する ClientHost と、処理を実行する CoreService は別のプログラムです。

## 管理画面を開く

インストール完了画面に表示された URL をブラウザーで開いてください。
既定の URL は `http://127.0.0.1:5081/` です。ポート番号を変更した場合は、指定した番号を使用してください。

画面の既定言語は英語です。画面上部の言語メニュー（Language）から日本語に変更できます。
言語設定はブラウザーに保存され、ワークフロー名や入力値、ログ本文は翻訳されません。

## 接続先を設定する

PC が表示されない場合や、接続先を追加する場合は次の手順で設定してください。

1. 右上の **Select connection** を開いてください。
2. **NIC** と **IPv4 on this interface** で、ClientHost が動く PC 自身のネットワークと IP アドレスを選択してください。
3. **Broadcast address** と **UDP port shared with Core** に、参加先のブロードキャスト先・UDP ポートを指定してください。
4. **Add or update this network** を押してください。
5. 検出されたピアの **Connect to this cluster and peer** を押してください。

管理画面の接続先を選択しても、その PC の CoreService が別のクラスターへ移動することはありません。
CoreService が参加するクラスターは、インストール時の設定で決まります。

## 接続状態を確認する

**Dashboard** の **Selected cluster** で、参加している PC とピアの状態を確認してください。
複数のクラスターをまとめて見る場合は **All clusters** を使用できます。

| 表示 | 確認すること |
| --- | --- |
| Joining | クラスターへ参加するための準備中です。 |
| Ready | 同期と参加条件の確認が完了しています。 |
| Syncing | 同期中です。長く続く場合は理由と通信状態を確認してください。 |
| Degraded | 内容の競合により、一部の処理が制限されています。競合しない範囲では動作を継続できます。 |
| Conflict | 識別情報や状態の競合があります。表示された理由を確認し、競合を解消してください。 |
| Detached | 利用者の操作でクラスターから離脱しています。再起動だけでは再参加しません。 |
| RecoveryOnly | 通常の処理を開始せず、復旧・診断を行える状態です。 |
| Unavailable | 通信や参加条件を確認できません。PC が停止したとは限りません。 |
| 未確認・通信不能 | 最後に確認できた値の場合があります。現在の稼働を保証する表示ではありません。 |

CoreService の稼働版は Dashboard に表示されます。
画面下部の製品名に続く版は、現在ブラウザーに読み込まれている UI の版です。

## 表示を変更する

- 言語は画面上部の言語メニューから変更してください。
- 日時の表示は Dashboard の「設定・保守」→「表示設定」でタイムゾーンを指定してください。既定は UTC です。
- ヘッダーのタイトル・画像は `branding.json` で変更できます。[設定方法](../reference/web-client.md#ヘッダーfaviconの差し替え)を参照してください。

表示用タイムゾーンはブラウザーごとの設定です。OS の時計やワークフローのスケジュールは変わりません。

## 試験的な機能を有効にする

Dashboard の「設定・保守」→「試験的な機能（experimental）」で「このブラウザーで試験的な機能を常に有効にする」にチェックを入れ、「保存」を押してください。すべての画面で、URLに `experimental=true` を付けた場合と同じ機能を利用できます。

設定はブラウザーに保存され、同じWebUIを開き直した後も保持されます。別のブラウザーや、ホスト名・ポート番号・HTTP/HTTPSが異なるWebUIには引き継がれません。開いている別のタブには、画面を開き直すと反映されます。

既定はオフです。チェックを外して保存すると、従来どおりURLに `experimental=true` を指定した画面だけで有効になります。常時有効を選んでいる間は、URLに `experimental=false` を指定しても有効です。

## 画面が古いままの場合

UI の更新が表示された場合は、未保存の編集内容を保管してから、同じ ClientHost を開いているタブやアプリをすべて閉じ、開き直してください。
キャッシュを更新する場合は `/ui-update.html` も利用できます。

ブラウザーに保存された画面は、ClientHost の停止中も開ける場合があります。
画面が開くことと、PC の状態を取得できることは別です。

Dashboard の集計方法、表示名、ブラウザーへのアプリ追加、保持上限は[管理画面の設定と表示仕様](../reference/web-client.md)にまとめています。
