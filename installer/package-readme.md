# Clutch-CS

## セットアップを始める

Windows では、このフォルダーの一つ上にある **Clutch-CS-Setup.exe** を起動してください。
セットアップからインストール・更新・修復・アンインストールを選択できます。

1. 言語と操作を選択してください。
2. 画面に従ってネットワーク・対象・設定を選択してください。
3. 実行内容を確認し、確認欄にチェックを入れて開始してください。
4. 完了画面で結果を確認してください。管理画面をインストールした場合は URL も表示されます。

配布 ZIP はすべて展開して使用してください。
起動用 EXE と `files` フォルダーの位置関係を保ったまま、フォルダー全体を移動できます。
