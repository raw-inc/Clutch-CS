## 使用する前に

入力値と実行先を確認してからインポートしてください。型が異なる値を接続する場合は、変換ノードで明示的に変換してください。

ワークフローの読込み・保存・反映は[ワークフローを作る](../../docs/guides/workflows.md)の手順を使用してください。定義内の置換用の値を残したまま有効にしないでください。
