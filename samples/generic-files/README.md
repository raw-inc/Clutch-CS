## 使用する前に

転送元・転送先のピアと、それぞれの PC のパスを変更してください。CoreService の実行アカウントが対象のファイルを読み書きできる必要があります。コピー先に同名の項目がないことも確認してください。

ワークフローの読込み・保存・反映は[ワークフローを作る](../../docs/guides/workflows.md)の手順を使用してください。定義内の置換用の値を残したまま有効にしないでください。
