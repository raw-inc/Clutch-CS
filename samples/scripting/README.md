# スクリプトで文字列配列を整える

[サンプル一覧](../README.md) · [スクリプトノードの設定と動作](../../docs/reference/nodes/scripting.md)

ラベルや項目名の配列から、前後の空白、空要素、重複を取り除くサンプルです。
C#・Python・JavaScript のうち、使いたい言語を一つ選んで試せます。外部機器、ネットワーク接続、追加パッケージは不要です。

| ファイル | 使用するノード | 実行ピアに必要な環境 |
| --- | --- | --- |
| [normalize-labels.csx](normalize-labels.csx) | `script.csharp` | CoreService に含まれる C# 実行環境 |
| [normalize-labels.py](normalize-labels.py) | `script.python` | Python 3.10 以降 |
| [normalize-labels.mjs](normalize-labels.mjs) | `script.javascript` | Node.js 24 以降 |

各ファイルはノードのコード欄に貼り付けるコードです。ワークフロー定義としてはインポートできません。

## 実行する

1. WorkflowEditor で新しいワークフローを作り、選んだ言語のスクリプトノードを追加してください。
2. 実行ピアを選択し、対応するファイルの内容をすべてコード欄へ貼り付けてください。Python・JavaScript では、そのピアの実行環境も選択してください。
3. 「コードと型を解析」を押し、引数 `values` と出力 `value` がどちらも文字列の配列として表示されることを確認してください。
4. 「引数の入力方式」で引数ごとの入力を選び、`values` に次の JSON 配列を設定してください。

   ```json
   ["  news ", "", "weather", "news", "News", " お知らせ ", "\t"]
   ```

5. 「プレビュー」(`control.preview`) ノードを追加し、スクリプトの `value` 出力からプレビューの `value` 入力へ接続してください。
6. [保存・反映の手順](../../docs/guides/workflows.md#保存して反映する)に従って保存し、上部ツールバーの「一回実行」を押してください。
7. プレビューに次の配列が表示されることを確認してください。

   ```json
   ["news", "weather", "News", "お知らせ"]
   ```

文字列は最初に現れた順に残ります。大文字・小文字は区別するため、`news` と `News` は別の値です。文字列の途中にある空白は残ります。
空の配列 `[]` や空白だけの要素を渡すと、出力は `[]` になります。数値や `null` を含む配列は入力型の検証で拒否されます。

## 一括入力で使う

「引数の入力方式」を一括入力へ変更し、`arguments` に次の JSON オブジェクトを設定してください。個別入力の配線がある場合は、先に外してください。

```json
{
  "values": ["  news ", "", "weather", "news", "News", " お知らせ ", "\t"]
}
```

解析・保存・反映後に一回実行すると、個別入力と同じ配列が返ります。出力 `value` は、文字列配列を受け取る後続ノードにも接続できます。
